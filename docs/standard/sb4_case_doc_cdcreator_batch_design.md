# 案件CS・CDCreator連携バッチ 設計メモ

## 1. 目的

WebUIからダウンロードした案件CS (`.xlsm`) に対して、Windows PC上のExcelを使用して次の処理を連続実行する。

1. 案件CSのCSシートへ項番を付与する
2. `runCdCreator` を実行する
3. 案件CSとCD用Excelを同じフォルダへ保存する

CDCreatorのVBAはそのまま利用し、MVPではシート選択や出力先確認などの画面操作を残す。

## 2. 結論

WindowsバッチからPowerShellを呼び出し、PowerShellからExcel COMを操作する。

```text
案件CS.xlsm
  ↓ ドラッグ＆ドロップ
run_case_doc_cdcreator.bat
  ↓
run_case_doc_cdcreator.ps1
  ↓ Excel COM
Excelデスクトップアプリ
  ├─ AssignNumbersOnActiveSheet
  └─ runCdCreator
       ├─ CSシート選択
       ├─ 出力先確認
       └─ CD用Excel生成
  ↓
案件CS.xlsm + CD用Excel.xlsx
```

ブラウザからローカルバッチを自動起動する機能は、ブラウザのセキュリティ制約があるためMVP対象外とする。

## 3. 配置案

```text
tools/CDCreator/batch/
  run_case_doc_cdcreator.bat
  run_case_doc_cdcreator.ps1
  README.md
  logs/
```

ユーザーには `batch` フォルダ一式を配布する。

## 4. 前提条件

### 4.1 必須環境

- Windows 10またはWindows 11
- Excelデスクトップアプリ
- PowerShell 5.1以降
- `.xlsm` 内に次の公開マクロが存在すること
  - `AssignNumbersOnActiveSheet`
  - `runCdCreator`
- 案件CSが書き込み可能であること
- 同じ案件CSを別のExcelで開いていないこと

### 4.2 マクロセキュリティ

Webブラウザからダウンロードした `.xlsm` は、Windowsによってインターネット由来のファイルとして扱われ、マクロがブロックされる場合がある。

MVPでは次のいずれかで対応する。

1. 推奨: 社内管理された「信頼できる場所」に案件CS作業フォルダを設定する
2. PoC: ファイルのプロパティからブロックを解除してから実行する
3. 将来: VBAへ会社証明書によるデジタル署名を付与する

マクロセキュリティをPC全体で無効化する運用は採用しない。

推奨作業フォルダ例:

```text
C:\ProcedureDB\case_docs\
```

## 5. ユーザー操作

1. WebUIで「保存先を選んで案件CSを生成」を押す
2. 保存ダイアログで案件CS作業フォルダを選択する
3. 案件CSを `run_case_doc_cdcreator.bat` へドラッグ＆ドロップする
4. Excelが開いたら、複数のCSシートがある場合はCD化するシートを選択する
5. 出力先確認で「はい」を選び、案件CSと同じフォルダを指定する
6. 完了メッセージを確認して「OK」を押す
7. 同じフォルダに案件CSとCD用Excelがあることを確認する

CSシートが1件だけの場合、CSシート選択フォームは表示されず自動選択される。

保存先選択に対応していないブラウザでは、従来どおりブラウザ設定に従ってダウンロードする。

## 6. バッチの入力

### 6.1 基本操作

案件CSをバッチへドラッグ＆ドロップする。

```bat
run_case_doc_cdcreator.bat "C:\ProcedureDB\case_docs\案件CS.xlsm"
```

### 6.2 入力チェック

次の条件を満たさない場合は、Excelを起動せず終了する。

- ファイルが存在する
- 拡張子が `.xlsm`
- 一時ファイル `~$` ではない
- 読み取り専用ではない
- ファイルが他プロセスで排他的に使用されていない

MVPでは一度に1ファイルだけ処理する。

## 7. 処理フロー

### 7.1 起動前

1. 入力ファイルを検証する
2. 入力ファイルと同じフォルダを出力先候補として記録する
3. 実行前のCD用Excel一覧を記録する
4. ログファイルを作成する

### 7.2 Excel起動

1. Excel COMの専用インスタンスを起動する
2. `Visible = True` とし、ユーザーがフォームを操作できるようにする
3. 外部リンクを更新せず案件CSを開く
4. 読み取り専用で開かれていないことを確認する

マクロ名は、別ブックの同名マクロと混同しないよう、ブック名を付けて実行する。

```text
'案件CS.xlsm'!AssignNumbersOnActiveSheet
'案件CS.xlsm'!runCdCreator
```

### 7.3 項番付与

`runCdCreator` と同じ基準で、シート名に `CS` を含むワークシートを採番候補とする。

候補シートごとに次を実行する。

1. 対象シートをアクティブ化する
2. `AssignNumbersOnActiveSheet` を呼び出す

`AssignNumbersOnActiveSheet` はアクティブシートだけを処理するため、PowerShell側で候補シートを順番にアクティブ化する。

この時点では案件CSを保存しない。

### 7.4 CDCreator実行

項番付与後に `runCdCreator` を呼び出す。

`runCdCreator` で発生する画面操作:

- CS候補が複数の場合: 対象CSシートをチェックして「OK」
- 出力先確認:
  - 「はい」: 案件CSと同じフォルダ
  - 「いいえ」: 任意フォルダを選択
  - 「キャンセル」: 中止
- 完了時: 作成結果を確認して「OK」

今回の要件では、出力先確認で「はい」を選択する。

### 7.5 保存判定

`runCdCreator` の終了後、入力ファイルと同じフォルダに新しいCD用Excelが生成されたか確認する。

対象ファイル名:

```text
app修正前_*_CD_yyyymmdd.xlsx
```

判定:

| 結果 | 案件CS | バッチ結果 |
| --- | --- | --- |
| CD用Excelが1件以上生成 | 保存する | 成功 |
| 生成なし | 保存しない | キャンセルまたは失敗 |
| 一部生成、一部失敗 | 保存する | 警告付き成功 |

生成なしの場合、項番付与を含む変更を保存せず案件CSを閉じる。

### 7.6 終了処理

1. 保存条件を満たした場合だけ案件CSを保存する
2. 案件CSを閉じる
3. Excelを終了する
4. COMオブジェクトを解放する
5. 実行結果を画面とログへ出力する

Excel、ブック、シートなどのCOMオブジェクトは `finally` 相当の処理で必ず解放する。

## 8. キャンセル時の扱い

### 8.1 CSシート選択をキャンセル

- CD用Excelを生成しない
- 案件CSを保存しない
- エラーではなく「キャンセル」として終了する

### 8.2 出力先選択をキャンセル

- CD用Excelを生成しない
- 案件CSを保存しない
- エラーではなく「キャンセル」として終了する

### 8.3 完了メッセージ

完了メッセージの「OK」は処理結果の確認操作であり、CD用Excelは既に保存済みである。

## 9. エラー処理

| エラー | 対応 |
| --- | --- |
| Excel未導入 | Excelが必要であることを表示して終了 |
| ファイルなし | 対象パスを表示して終了 |
| `.xlsm` 以外 | 対象外形式として終了 |
| ファイル使用中 | Excelを閉じて再実行するよう表示 |
| マクロなし | 不足しているマクロ名を表示 |
| マクロブロック | 信頼できる場所またはブロック解除を案内 |
| CSシートなし | シート名に `CS` を含む対象がないことを表示 |
| 採番失敗 | CD作成を実行せず終了 |
| CD作成なし | キャンセルまたはVBAログ確認を案内 |
| Excel異常終了 | COM解放を試み、ログへ記録 |

VBA内部の詳細エラーは、案件CS内のログシートとバッチログの両方を確認する。

## 10. ログ

ログ例:

```text
tools/CDCreator/batch/logs/
  case_doc_cdcreator_20260727_153000.log
```

記録項目:

- 実行日時
- 入力ファイル名
- 入力フォルダ
- 対象CSシート名
- 採番実行結果
- `runCdCreator` 呼び出し開始・終了
- 生成されたCD用Excel
- 保存結果
- エラー内容

パスワードや案件固有のコマンド内容はログへ出力しない。

## 11. 多重実行

- 同じ案件CSに対する同時実行は禁止する
- バッチ起動時にロックファイルを作成する
- 正常終了・異常終了のどちらでもロックを解除する
- ロックが残っている場合は、別の処理が動いていないことを確認してから再実行する

ロックファイル例:

```text
案件CS.xlsm.cdcreator.lock
```

## 12. MVP対象外

- WebUIからローカルバッチを直接起動する
- サーバー上でExcelを自動操作する
- `runCdCreator` のフォームを自動クリックする
- 完全無人実行
- CDCreatorをPythonまたはAPIへ移植する
- 複数案件CSの一括処理
- VBAのデジタル署名基盤構築

## 13. 将来改善

### 13.1 VBAへ引数付き入口を追加

将来的には、既存の `runCdCreator` を残したまま、バッチ専用マクロを追加する。

例:

```vb
Public Function RunCdCreatorBatch( _
    ByVal outputFolder As String, _
    ByVal targetSheetNames As String _
) As Long
```

これにより、次を省略できる。

- CSシート選択フォーム
- 出力先確認
- 完了メッセージ

戻り値で作成件数を受け取れるため、キャンセルと失敗の判定も明確になる。

### 13.2 VBA署名

社内配布時は、信頼できる発行元として会社証明書でVBAへ署名する。

## 14. PoC確認項目

1. 1つのCSシートを持つ案件CSで、採番とCD生成が成功する
2. 複数CSシートから一部を選択してCD生成できる
3. 生成された案件CSとCD用Excelが同じフォルダにある
4. 案件CSのマクロと既存シートが保持される
5. シート選択をキャンセルした場合、案件CSが変更されない
6. 出力先選択をキャンセルした場合、案件CSが変更されない
7. CD用Excelの同名候補がある場合も既存ファイルを上書きしない
8. マクロブロック時に、ユーザーが原因と対処を判断できる
9. Excel異常終了後に不要なExcelプロセスが残らない

## 15. 実装順

1. PowerShellの入力検証とExcel起動を実装する
2. CSシート列挙と項番付与を実装する
3. `runCdCreator` 呼び出しを実装する
4. 生成ファイル検出と保存判定を実装する
5. キャンセル・エラー処理とログを実装する
6. `.bat` のドラッグ＆ドロップ入口を作成する
7. 案件CSのコピーを使ってPoC確認する
