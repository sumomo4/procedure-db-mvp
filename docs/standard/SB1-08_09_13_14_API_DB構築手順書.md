Sprint 1 の FastAPI 基本構成、疎通確認API、DB接続設定、DB接続確認を実施できる状態にする。

## 2. 対象バックログ

| --- | --- |

| SB1-09 | 疎通確認用APIを実装する |

## 3. 作成した主なファイル

| ファイル | 内容 |

| `apps/standard/backend/app/main.py` | FastAPIアプリ作成、共通例外ハンドラ |

## 4. ローカルAPI起動

```powershell
cd apps\standard\backend
python -m pip install -r requirements-dev.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API疎通確認:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/health
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

## 5. Docker Compose起動

standard構成のみを起動する。

前提:

- Docker Desktop の Linux Engine が起動していること
- `docker compose -f docker-compose.yml -f docker-compose.standard.yml config` が成功すること

```powershell
docker compose -f docker-compose.yml -f docker-compose.standard.yml up -d --build
```

DB接続確認:

```powershell
Invoke-RestMethod http://localhost:8000/api/v1/health/db
```

補足:

- Windows側で `127.0.0.1:8000` を別プロセスが占有している場合、Docker公開ポート確認では `localhost:8000` を使用する

停止:

```powershell
docker compose -f docker-compose.yml -f docker-compose.standard.yml down
```

## 6. テスト

```powershell
cd apps\standard\backend
python -m pytest
```

テスト対象:

- 設定値からDB接続URLが生成できること
- 疎通確認APIが共通レスポンスで応答すること
- DB接続確認APIが成功 / 失敗時に共通レスポンスで応答すること
- DB接続確認処理が正常系、接続失敗、想定外の戻り値を扱えること
