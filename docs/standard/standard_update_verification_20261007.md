## セキュリティ上の留意点

現行コミットの依存関係を変更せずにビルドしています。`npm audit --omit=dev` の結果は **High 2パッケージ**（`react-router` / `react-router-dom`）です。双方は関連する依存関係であり、独立した脆弱性が2種類という意味ではありません。使用バージョンは7.14.1です。

今回のUIはNginx配信の静的SPAとBrowserRouterを使用しています。React RouterのFramework Mode限定の警告については、実際の構成と区別して評価する必要があります。一方、クライアント側の遷移に関する警告もあるため、すべて影響なしとは判断していません。

- [Framework Mode限定のDoSに関する公式アドバイザリ](https://github.com/remix-run/react-router/security/advisories/GHSA-chx6-hx7r-mcp5)
- [未信頼の遷移先に関する公式アドバイザリ](https://github.com/remix-run/react-router/security/advisories/GHSA-wrjc-x8rr-h8h6)

機能テスト成功はセキュリティ確認完了を意味しません。本番適用前に、依存関係更新を別変更として回帰確認するか、今回構成での影響評価と社内判断を行ってください。今回の作業で `npm audit fix` や依存関係の自動更新はしていません。監査のJSON結果を同梱しています。
